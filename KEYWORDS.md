# GitHub Repository SEO Setup

## Repository Description (set this on GitHub)

Go to your repo → click the ⚙️ gear icon next to "About" → paste this as the description:

```
Use Claude Code for free with Kimi, GLM, DeepSeek, OpenRouter and any OpenAI-compatible provider. Free Claude Code gateway — no Anthropic API key needed.
```

## Why Topics Matter

GitHub topics appear in Google search results directly. When someone searches "free claude code" or "claude code without api key", these topics help Google understand what your repo is about.
