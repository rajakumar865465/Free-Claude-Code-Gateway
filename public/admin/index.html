      Error Reference

      401
      Unauthorized

      Invalid or missing API key. Update the upstream key in Settings → Provider Connection.

      403
      Permission Denied

      API key is valid but lacks permission for this model. Try fetching available models.

      404
      Model Not Found

      The model name is unknown to the provider. Check Model Router and Default Model.

      429
      Rate Limited

      Provider rejected the request due to quota. Wait, reduce frequency, or upgrade.

      500
      Provider Server Error

      Upstream provider encountered an internal error. Retry after a short delay.

      timeout
      Request Timeout

      Provider did not respond within the configured timeout. Increase it in Settings → Limits.
